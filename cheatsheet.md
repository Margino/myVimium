# Vimium — конспект горячих клавиш

---

# 1. Перемещение по странице

## Вертикальная прокрутка

| Команда | Значение |
|---------|----------|
| `j` | Прокрутить вниз |
| `Ctrl + e` | Прокрутить вниз (альтернативная команда) |
| `k` | Прокрутить вверх |
| `Ctrl + y` | Прокрутить вверх (альтернативная команда) |
| `d` | Прокрутить вниз на полстраницы |
| `u` | Прокрутить вверх на полстраницы |
| `gg` | Перейти в самое начало страницы |
| `G` | Перейти в самый низ страницы |

## Горизонтальная прокрутка

| Команда | Значение |
|---------|----------|
| `h` | Прокрутить влево |
| `l` | Прокрутить вправо |
| `zH` | Переместиться в самый левый край страницы |
| `zL` | Переместиться в самый правый край страницы |

## Навигация между фреймами

> **Фрейм (Frame)** — отдельная встроенная область страницы (например, встроенная карта, видео, документ).

| Команда | Значение |
|---------|----------|
| `gf` | Перейти к следующему фрейму |
| `gF` | Перейти к основному (верхнему) фрейму страницы |

---

# 2. Работа со ссылками

| Команда | Значение |
|---------|----------|
| `f` | Открыть ссылку в текущей вкладке |
| `F` | Открыть ссылку в новой вкладке |
| `Alt + f` | Открыть несколько ссылок в новых вкладках |
| `yf` | Скопировать адрес ссылки |

## Переход между страницами

Работает на сайтах, где есть ссылки **Previous / Next**, «<» / «>».

| Команда | Значение |
|---------|----------|
| `[[` | Перейти на предыдущую страницу |
| `]]` | Перейти на следующую страницу |

---

# 3. Работа с адресом страницы (URL)

> **URL (Uniform Resource Locator)** — веб-адрес страницы.

| Команда | Значение |
|---------|----------|
| `yy` | Скопировать адрес текущей страницы |
| `p` | Открыть адрес из буфера обмена в текущей вкладке |
| `P` | Открыть адрес из буфера обмена в новой вкладке |
| `ge` | Отредактировать текущий адрес |
| `gE` | Отредактировать текущий адрес и открыть в новой вкладке |

## Навигация по структуре URL

Пример:

```text
https://docs.python.org/3/library/pathlib.html
```

| Команда | Результат |
|---------|-----------|
| `gu` | Подняться на один уровень вверх → `https://docs.python.org/3/library/` |
| `gU` | Перейти в корень сайта → `https://docs.python.org/` |

# 4. Поиск, открытие страниц и Vomnibar

> **Vomnibar** — командная строка Vimium для поиска по истории, закладкам, открытым вкладкам и ввода URL.

| Команда | Значение |
|---------|----------|
| `o` | Открыть URL, запись истории или закладку |
| `O` | То же в новой вкладке |
| `T` | Найти среди открытых вкладок |
| `b` | Найти и открыть закладку |
| `B` | Открыть закладку в новой вкладке |

---

# 5. Поиск текста на странице

| Команда | Значение |
|---------|----------|
| `/` | Начать поиск текста |
| `n` | Следующее совпадение |
| `N` | Предыдущее совпадение |
| `*` | Искать выделенный текст вперёд |
| `#` | Искать выделенный текст назад |

---

# 6. Режимы работы (Modes)

| Команда | Значение |
|---------|----------|
| `i` | Режим вставки (*Insert Mode*) — временно отключить Vimium и печатать текст |
| `v` | Визуальный режим (*Visual Mode*) — выделение текста |
| `V` | Построчный визуальный режим (*Visual Line Mode*) |
| `gi` | Перейти к первому полю ввода на странице |

---

# 7. История браузера

| Команда | Значение |
|---------|----------|
| `H` | Назад |
| `L` | Вперёд |

---

# 8. Работа со вкладками

## Создание и закрытие

| Команда | Значение |
|---------|----------|
| `t` | Создать новую вкладку |
| `x` | Закрыть текущую вкладку |
| `X` | Восстановить закрытую вкладку |
| `yt` | Дублировать текущую вкладку |
| `W` | Переместить вкладку в новое окно |

## Переключение

| Команда | Значение |
|---------|----------|
| `gt` или `K` | Следующая вкладка |
| `gT` или `J` | Предыдущая вкладка |
| `^` | Вернуться к предыдущей посещённой вкладке |
| `g0` | Первая вкладка |
| `g$` | Последняя вкладка |

## Управление вкладками

| Команда | Значение |
|---------|----------|
| `<<` | Переместить вкладку левее |
| `>>` | Переместить вкладку правее |
| `Alt + p` | Закрепить или открепить вкладку |
| `Alt + m` | Включить или выключить звук вкладки |

# 9. Масштаб страницы

| Команда | Значение |

| `zi` | Увеличить масштаб |

|---------|----------|
| `m` | Создать метку |

| Команда | Значение |

# Памятка по префиксам

| Префикс | Значение |
|---------|-----------|
| `g` | **Go** — переход или навигация (`gg`, `gU`, `gu`, `gt`, `gT`, `gf`) |
| `z` | Масштабирование или положение страницы (`zi`, `zo`, `zH`, `zL`) |
| `y` | **Yank** — копирование (`yy`, `yf`, `yt`) |
| `m` | **Mark** — поставить метку |
| `` ` `` | Перейти к метке |
| `f` | **Follow** — открыть ссылку |
| `i` | **Insert** — режим ввода |
| `v` | **Visual** — режим выделения |
