# 6. Работа с закладками

## Команды Vimium (поиск и открытие)

| Команда | Действие |
|---------|----------|
| `b` | Поиск по закладкам |
| `B` | Поиск по закладкам (откроется в новой вкладке) |
| `Ctrl` + `j` | Переместиться вниз по результатам поиска |
| `Ctrl` + `k` | Переместиться вверх по результатам поиска |

> b — bookmarks (закладки);\
> Команда открывает строку Vomnibar, отфильтрованную исключительно по  закладкам (история и глобальные поисковые запросы там отображаться не будут).


## Браузерные команды (создание и управление)

| Команда | Действие |
|---------|----------|
| `Ctrl` + `d` | Добавить текущую страницу в закладки |
| `Ctrl` + `Shift` + `d` | Сохранить ВСЕ открытые вкладки в новую папку |
| `Ctrl` + `Shift` + `b` | Показать / скрыть панель закладок браузера |
| `Alt` + `Ctrl` + `b` | Открыть дспетчер закладок (Bookmark Manager) |

> Vimium не умеет самостоятельно создавать или удалять закладки, для полноценного менеджмента используются стандартные комбинации браузера.
