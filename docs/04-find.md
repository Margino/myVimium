# 4. Поиск на странице

## Поиск текста

| Команда | Действие |
|---------|----------|
| `/` | Начать поиск на странице |
| `n` | Перейти к следующему совпадению |
| `N` | Перейти к предыдущему совпадению |

Нажимаем `/` → вводим поисковый запрос → нажмаем <kbd>Enter</kbd>. Все совпадения будут подсвечены на странице.

**Примеры использования:**\

/текст → Enter → n → n → n\
\
/текст → Enter → N ← N ← N

---

## Поиск выделенного текста

| Команда | Действие |
|---------|----------|
| `*` | Найти выделенный текст вперёд |
| `#` | Найти выделенный текст назад |

Команды используют уже выделенный текст в качестве поискового запроса. Удобно, когда нужно быстро найти другие вхождения слова или фразы.
