# 4. Поиск на странице

## Поиск текста

| Команда | Действие |
|---------|----------|
| `/` | Начать поиск на странице |
| `n` | Перейти к следующему совпадению |
| `N` | Перейти к предыдущему совпадению |

Нажимаем `/` → вводим поисковый запрос → нажмаем <kbd>Enter</kbd>. Все совпадения будут подсвечены на странице.

**Примеры использования:**

/текст → Enter → n → n → n

/текст → Enter → N ← N ← N
