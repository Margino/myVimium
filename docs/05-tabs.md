# 4. Работа с вкладками

## Управление вкладками

| Команда | Действие |
|---------|----------|
| `t` | Создать новую вкладку |
| `x` | Закрыть текущую вкладку |
| `X` | Восстановить последнюю закрытую вкладку |
| `alt` + `p` | Закрепить / открепить текущую вкладку |

> t — tab (вкладка);\
> x — close (закрыть).

## Навигация между вкладками

| Команда | Альтернатива | Действие |
|---------|--------------|----------|
| `J` | `gT` | Перейти на одну вкладку влево |
| `K` | `gt` | Перейти на одну вкладку вправо |
| `g0` | — | Перейти на первую вкладку |
| `g$` | — | Перейти на последнюю вкладку |
| `^` | — | Переключиться на последнюю активную вкладку |

> J / K — перемещение влево/вправо (удобно для браузера);\
> gt / gT — классические команды вкладок из оригинального Vim (go tab).

## Поиск и перемещение вкладок

| Команда | Действие |
|---------|----------|
| `T` | Искать среди открытых вкладок |
| `<<` | Переместить текущую вкладку влево |
| `>>` | Переместить текущую вкладку вправо |
| `W` | Переместить текущую вкладку в новое окно |
