# 5. Работа с историей

## Перемещение по истории текущей вкладки

<!-- ![Перемещение по истории](../img/history-nav.jpg) -->

| Команда | Действие |
|---------|----------|
| `H` | ← Перейти назад по истории |
| `L` | → Перейти вперед по истории |

> H / L — перемещение влево/вправо по горизонтали (аналог в Vim);\
> Заглавные буквы используются, так как строчные `h` и `l` заняты под посимвольную прокрутку страницы.

## Поиск по истории

| Команда | Действие |
|---------|----------|
| `o` | Открыть панель поиска |
| `O` | Открыть панель поиска в новой вкладке |
| `Ctrl` + `j` | Переместиться вниз по результатам поиска |
| `Ctrl` + `k` | Переместиться вверх по результатам поиска |

> o — open (открыть панель поиска Vomnibar);\
> Регистр клавиши определяет поведение: строчная `o` — откроет в текущей вкладке, заглавная `O` — в новой;\
> `Ctrl` + `j`/`k` — стандартный для Vim способ навигации по спискам (вместо стрелок).
